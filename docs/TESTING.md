# Приёмка и тесты

## Безопасная проверка без колонки

```bash
python3 -m py_compile bridge/*.py ha/*.py
python3 -m unittest discover -s tests -p 'test_contract.py' -v
# требуется установленный libopus.so и ffmpeg для медиа-тестов
```

В `tests/test_synthetic.py` есть реальный стендовый тест: задайте `ROOM_GPT_TEST_AUDIO_FILE` (путь к собственному PCM16 16k), `ROOM_GPT_TEST_URL` и запускайте тест **только на отдельном VPS-мосте**, не отправляя запись в Git. Он проверяет получение Ogg/Opus и события `ready`.

Для исходника станции:

```bash
cd station
go test ./...
go build ./...
```

Не считать обычную компиляцию доказательством работы на физической Lite 1. Целевая платформа станции — Linux ARM64; сборка должна учитывать native зависимости Opus и актуальный Go toolchain.

## Обязательная физическая приёмка перед переключением

- Штатная Алиса работает до/после переключения, будильники и громкость не пропадают.
- Говорить длинной фразой с паузами, слушать полный ответ; начало аудио не теряется.
- Перебить модель своим голосом во время её ответа — она должна остановиться, распознать новую речь и не начать диалог сама с собой.
- При внезапном обрыве Wi-Fi и восстановлении соединения не должны висеть незавершённые `VoiceInput` и бесконечные запросы.
- Проверить рост памяти/логов, корректность shutdown, cold restart.
- Сопоставить лог станции, HA и VPS по UTC и идентификаторам, измерить время от конца речи до фактического звука на динамике.

**Известная зона риска**: конкурентные запросы штатного SpeechKit и голосового Codex. В ноябре были `waitForResult timeout elapsed: 12000 ms`, и Quasar Bridge иногда регистрировал поздние ответы. Требуется отдельная проверка и корректная отмена устаревших запросов. Не объявлять проблему решённой без повторного полного теста.

## Откат

Сначала в Home Assistant вернуть `Алиса` / `Quasar Assistant`, убедиться, что аудио в норме. Не трогать заводской `maind`, не делать сброс до заводских настроек. Перед первым развёртыванием новой сборки сохранить действующий бинарник, конфигурацию, hash, скрипт запуска и процедуру восстановления.
