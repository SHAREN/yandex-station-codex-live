# Задачи до выпуска стабильной версии

1. Сверить исходник `station/main.go` с фактически установленным ARM64-агентом и сохранить бинарник/хеш до замены. Старую экспериментальную ветку не объявлять production без доказательств.
2. Добавить `codex-mode` HTTP-эндпоинт в Pipecat, подтвердить, что `GPT Live` включает только новую полнодуплексную ветку, а `Алиса` и `Quasar Assistant` сохраняются.
3. Проверить `VoiceInput` lifetime на реальной колонке: штатный SpeechKit не должен оставаться висеть после перехода в Codex и выдавать `waitForResult timeout elapsed: 12000 ms`.
4. Проверить штатные VQE/AEC и барж-ин: модель не слушает саму себя, но слышит пользователя во время воспроизведения. Не решать задачу глушением микрофона.
5. Зафиксировать единую установку, rollback и SHA-проверку без правки оригинального `maind`.
6. Отдельно подключить контролируемые инструменты/агента при необходимости; отсутствие инструментов в голосовой модели не нужно скрывать.
7. Проверить ограничения и допустимость стороннего OAuth-использования для Codex без утверждения об официальной поддержке.
