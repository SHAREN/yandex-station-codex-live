# Безопасность и модель доступа

- Репозиторий **публичный**. Исходники, Git-история, Issues и журналы публичного CI доступны всем: не размещать в них домашние адреса, домены, MAC, пароли или токены.
- Никакого `OPENAI_API_KEY` в исходниках: OAuth для Codex хранится и обновляется отдельно в CLIProxyAPI, здесь не копируется.
- На HA/VPS никогда не пересылать необработанные OAuth-токены, файлы авторизации Codex или пароль роутера.
- VPS-сервис слушает `127.0.0.1`. На внешний доступ — обязательны TLS, Basic Auth, rate limit, контроль источников, короткие тайм-ауты и ограничения размеров кадров.
- TLS проверяется обычным клиентом; нельзя включать `ssl=False` или `verify=False`.
- Станционные бинарники, прошивки, аудиозаписи, приватные IP, журналы диалогов и дампы — только вне Git. `.gitignore` не защищает уже закоммиченные файлы.
- Самописец задержек выключен по умолчанию; включение — только на одну явно подтверждённую сессию, с автоматическим пределом объёма и временем жизни.
- Развёртывание должно быть безопасным: сохранить действующие файлы и хеши, развернуть в отдельном сервисе, запустить тест, после подтверждения переключить режим; при ошибке вернуть Алису.
- CLIProxyAPI — сторонний компонент. Его реализация и условия использования могут изменяться; подписка Codex не означает официальной поддержки произвольных сторонних voice-приложений и не гарантирует отсутствия лимитов.
