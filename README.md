# Yandex Station ↔ Codex GPT-Live (full duplex)

**Голосовая интеграция Яндекс Станции со штатной активацией «Алиса», VQE/AEC и двусторонним голосовым режимом через `gpt-live-1-codex`. Без Gemini, без отдельного OpenAI API-ключа в этом мосте.**

> **Статус: alpha / восстановление исходников.** VPS Python-мост + Home Assistant relay проверены на действующей системе и синтетическим звуком. Исходник агента самой станции восстановлен из старого экспериментального проекта и адаптирован под Codex, но **новая сборка из этого репозитория ещё не развёрнута и не прошла физический тест**. Не устанавливайте её поверх исправной колонки без бэкапа и проверки.

## Что делает

- Сохраняет родное слово активации, микрофоны, штатный аудиотракт и обработку VQE/AEC, если устройство/root позволяет к ним подключиться.
- По выбору `GPT Live` переводит одну голосовую сессию в полноценный **full duplex**: речь пользователя продолжает поступать пока ответ воспроизводится, перебивание поддерживается.
- Отправляет PCM от Станции через Home Assistant → защищённый WebSocket → VPS, где `aiortc` устанавливает голосовой WebRTC-сеанс через **CLIProxyAPI с действующим Codex OAuth**.
- При переключении в обычную Алису сохраняет штатный путь (при наличии совместимого Quasar Bridge).
- Не требует прописывать OpenAI API key в проекте. **Это не официальная гарантия бесплатной или неограниченной работы:** Codex OAuth/CLIProxyAPI — отдельная, неофициальная интеграция; доступность модели, правила использования, лимиты и возможные ограничения определяются поставщиками.

## Архитектура

```text
                      Яндекс Станция Lite 1 (root)
     штатное wake word / микрофоны / VQE / АEC / динамик
                             │ PCM16 16k
                             ▼
                   station/main.go (Go)
                             │ LAN WebSocket /audio
                             ▼
      Home Assistant: Pipecat Assist Proxy (ha/room_gpt_live_station.py)
                 │ выбор «GPT Live» / «Алиса»
                             │ WSS + Basic Auth
                             ▼
             VPS: bridge/app.py (Python/aiortc)
                             │ WebRTC offer
                             ▼
    CLIProxyAPI ── Codex OAuth подписки ── gpt-live-1-codex
                             │ RTP Opus
                             ▼
           VPS Ogg/Opus → HA relay → Станция → динамик
```

**Gemini не является частью голосового провайдера этого проекта.** Некоторые старые внутренние Quasar-endpoint'ы называются `/__gemini/...` исключительно из-за совместимости со старым бинарным протоколом; они **не обращаются к Gemini API**.

## Состав

- `bridge/app.py` — рабочий серверный мост PCM ↔ WebRTC GPT-Live.
- `bridge/opus_stream.py` — потоковый Ogg/Opus, `bridge/latency_trace.py` — диагностический самописец, включается только явным разрешением на одну сессию.
- `ha/room_gpt_live_station.py` — проверенный relay для Home Assistant Pipecat, без чтения OAuth-секретов.
- `ha/codex_mode.py` — вспомогательный HTTP-обработчик выбора режима для Go-агента.
- `station/main.go` — перенесённый исходник Lite 1 (VQE/воспроизведение/перехват wake), адаптация Codex-контроллера; **пока не равен проверенному production-бинарнику**.
- `deploy/` — конфигурационные примеры Nginx/systemd и переменных окружения.
- `docs/` — архитектура, воспроизводимое развёртывание, безопасность и план тестов.

## Как использовать

Начните с [схемы и ограничений](docs/ARCHITECTURE.md), затем [развёртывание](docs/DEPLOYMENT.md) и [приёмочные тесты](docs/TESTING.md). Для станции **требуется root-доступ и совместимый Quasar Bridge**; простой установкой приложения в Яндекс Дом этот режим не включается.

Базовые параметры VPS (пример; адрес CLIProxyAPI замените своим):

```bash
export CODEX_PROXY_CALL_URL=http://127.0.0.1:8317/v1/realtime/calls
export ROOM_GPT_LIVE_PORT=18771
python3 bridge/app.py
```

Внешний WebSocket обязательно закрыть TLS + авторизацией в обратном прокси. Сервер по умолчанию слушает только `127.0.0.1`.

## Оплата и подписка

Текущий вариант использует **авторизацию Codex OAuth в отдельно установленном CLIProxyAPI**, а не ключ проекта OpenAI Platform. В коде **нет** вызова платного OpenAI API по отдельному API-ключу. Это **не** обещание, что подписка разрешает любой внешний сценарий или что не будет лимитов/блокировок: перед использованием проверьте действующие условия OpenAI и CLIProxyAPI.

## Отношение к другим репозиториям

[Native Alice + Custom LLM](https://github.com/SHAREN/yandex-station-native-alice-llm) — **штатный SpeechKit ASR + нативный TTS Алисы и текстовая модель**, отдельная архитектура. [Quasar Bridge](https://github.com/SHAREN/quasar-bridge) — общее ядро перехвата. Этот репозиторий — **непосредственный голосовой full-duplex через GPT-Live-Codex**, не следует смешивать истории релизов.

## Безопасность и лицензии

Не коммитить OAuth-кэш, htpasswd, ключи, аудиозаписи, персональные данные, прошивку, бинарник `maind` и сетевые адреса своего дома. Репозиторий публичный, но это само по себе не даёт разрешения на повторное использование кода: отдельная лицензия проекта пока не выбрана, лицензии сторонних компонентов сохраняются. См. [SECURITY](docs/SECURITY.md).
